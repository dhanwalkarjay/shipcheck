Open-source skills for Alan

Know whether agent-written code is safe to ship.

Coding agents write code faster than people can review it. ShipCheck turns “I hope this is fine” into evidence a reviewer can read in two minutes, and keeps work resumable between people and agents.

View on GitHub Install in Alan

Three skills

PR trust report

pr-trust-report scans a change for risk, maps every task requirement to evidence, and saves a one-page report as a task artifact.

Plan lint

plan-lint scores a plan on seven dimensions, quotes the vague lines, and gives paste-ready rewrites before any code is written.

Task handoff

task-handoff records state, decisions and reasons, dead ends, and the next three actions so another agent can continue without the chat.

Real output

An agent added a retry feature. A skim would say “looks fine”. The trust report found this:

BlockedRisk scan: HIGH · 6 files (+19 / −8) · 2 test files touched

The agent then read the code and found what no scanner can: retry(req) is called but never defined, so every request would crash. Each requirement gets a verdict (Met, Partial, Missing, Unverified) with a path:line as evidence. No evidence means “Unverified”, never “Met”.

How it works

The part that must be reliable is not left to a model. pr-trust-report bundles a deterministic scanner (Python standard library, no network, no model calls) that gives the same answer every time and costs nothing to run. The agent then decides which signals are real, and every report ends with a “Not checked” section so unknowns stay visible.

Install in Alan

  1. Open Skills, then Team skills.
  2. Choose Import, then From GitHub.
  3. Paste https://github.com/dhanwalkarjay/shipcheck, review the files, and choose Add to team.

Then type / in any session and pick a skill, or just ask.

Run a trust report on this branch against the task requirements.
Lint the plan before we start building.
Write a handoff for this task, I’m stopping for today.

Use the scanner anywhere

python3 risk_scan.py --base main --head HEAD --format md
python3 risk_scan.py --base main --fail-on high   # exit code 2 in CI

A ready-made GitHub Action in the repo runs it on every pull request.
